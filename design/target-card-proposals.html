目标卡片优化方案

5 个方向，均基于应用现行的新拟态设计语言（同一表面色、双向柔和阴影、圆角与 hover 凸起），可直接替换现有 TargetCard。每个方案展示「正常」与「告警」两种状态；卡片宽度按左栏实际约 300px 还原。

所有方案共同遵守的三条准则（来自 UX 规范检索）：① 状态不只靠颜色区分，一律「颜色 + 图标 + 文字」；② 正文对比度 ≥ 4.5:1（状态文字统一用深色变体）；③ 所有数值使用等宽数字（tabular-nums），上下对齐不跳动。深色主题下所有颜色由主题 token 派生，切换即适配。

延迟主视觉 · 数字优先

监控工具气质

把「用户最关心的一个数」——当前平均延迟——放大为卡片主视觉（30px 粗体，健康时中性色、告警时变琥珀/红），发送数与丢包率退为右下角次要信息。列表快速下滑时，视线路径零成本：先看到大数字，再看名字。适合把 Pingo 当「仪表盘」用的场景。

左缘状态轨 · 三行扫读

推荐

卡片左缘加一条 4px 圆角状态色轨（绿=正常 / 琥珀=告警 / 灰=停用），列表呈「书脊」效果，滚动时哪台出问题凭余光即可定位。内容压缩为固定三行：①别名 + 状态文字（图标）②IP + 当前延迟 ③发送/丢包/超时次数。每行职责单一，文本不再挤成小 chip。

列表扫读性最强，余光可辨状态 三行定高，N 张卡片高度一致、最整齐 色轨边缘占用约 6px 横向空间

迷你趋势 · 图形常驻

信息密度最高

卡片右上角常驻一条 72×28 的延迟迷你走势（近 N 个采样，蓝线；告警时转红并在超时处跌底），别名前加状态圆点。文本指标保持一行 chip 但减到三个。相当于把详情页图表「预告片」放进列表，不用点开就能预判趋势——代价是每个卡片多维护一条轻量 SVG。

不用点开详情即可看趋势，监控价值最高 图形元素提升卡片辨识度与精致感 实现成本最高（uPlot 数据复用一条 SVG polyline） 卡片高度略增，信息密度接近上限

健康条 · 在线率可视化

最直观的比例感

把抽象的「丢包率 %」画成一条内嵌健康条：绿色填充比例 = 在线率，告警时填充变琥珀且肉眼可见地「缺了一块」，停用时整条置灰。数字信息只留两行：别名 + IP，以及「平均延迟 / 发送数」。适合希望列表整体像一面状态墙的审美方向。
